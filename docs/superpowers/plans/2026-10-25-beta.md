# PrintLab Beta Implementation Plan

> **For agentic workers:** Use bounded parallel implementation tasks and an independent whole-branch review. Do not merge this branch into main.

**Goal:** Deliver an isolated beta with assembly connectors, multi-edge finishing and a focused home.
**Architecture:** Extend existing Manifold snapshot services, optional model metadata, and the current React navigation. Separate hosting identity, storage and release branch from production.
**Tech Stack:** React, TypeScript, Three.js, Manifold WASM, Zustand, Dexie, Vitest, Playwright, Sites Worker.
**Spec:** ../specs/2026-10-25-beta-design.md

## Global constraints
- Beta only until explicit user instruction to merge to main.
- Preserve legacy projects, source geometry recovery, undo/redo and existing routes.
- No arbitrary generated code or physical engineering certification.

## Review focus
- Joint on a thin, hollow or disconnected cut face must reject unsafe geometry.
- Parameter/project edits while preview runs must prevent stale apply.
- Mesh conversion must save recovery before mutation, including save failure.
- Legacy edge-treatment documents must load identically.
- Beta links, canonical URLs, storage and release tooling must not target production.
